# Password Strength Checker

A simple web app that checks how strong a password is in real time and tells you how to improve it.

**Live demo:** https://vandanapvl447-a11y.github.io/password-strength-checker/

## Features
- Real-time strength meter (Very Weak to Very Strong)
- Colour-coded strength bar
- Suggestions to improve the password
- Show/hide password option
- Runs fully in the browser; no password is stored or sent anywhere

## How it works
The checker scores a password on these rules:
- At least 8 characters
- Lowercase letter
- Uppercase letter
- Number
- Special character
- Bonus point for 12 or more characters
